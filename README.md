# 🌍 EYEWHERE? : Ultimate Travel & Area Intelligence System

**EYEWHERE?** is an advanced terminal-based area intelligence and travel assistant designed to run on mobile environments (Termux) with local **MariaDB / MySQL** database persistence.

---

## 🚀 Features
* **Dynamic Origin & Destination Tracking:** Automatically sets a baseline location (e.g., Danao, Cebu) and computes precise great-circle distances (in km) to any scanned destination worldwide.
* **Real-Time Weather Intelligence:** Simulates and delivers comprehensive meteorological conditions, temperature, humidity, and forecasts.
* **Environmental Analysis:** Details local ecosystems, terrain layouts, and regional profiles.
* **Safety Measures & Guidelines:** Generates emergency directives, precautions, and travel safety protocols.
* **MariaDB Database Logging:** Automatically records all user searches, metrics, and timestamps locally into `eyewhere_db`.

---

## 🛠️ Tech Stack
* **Language:** Python 3
* **Database:** MariaDB / MySQL (`PyMySQL` connector)
* **Environment:** Termux & Acode (Android)
* **Version Control:** Git & GitHub (`Kenken` repository)
